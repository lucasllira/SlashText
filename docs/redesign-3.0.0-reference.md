## Síntese aplicada

- Usar a família visual recorrente, não copiar inconsistências entre variações.
- Shell nativo e compacto, navegação horizontal, ciano funcional e poucas camadas.
- Versões 15–21 orientam densidade, hierarquia e tema escuro; versões 1–14
  confirmam paridade no tema claro e detalhes alternativos.
- Ícones serão vetoriais/reutilizáveis; símbolos Unicode frágeis não serão usados.
- Mockups de Estatísticas contêm números, tendências e séries ilustrativas. Só
  serão mostrados dados que a aplicação realmente possui.
- Funções existentes ausentes no mockup — importação, presets completos de mídia,
  histórico detalhado, migração, update, rollback e estados de erro — permanecem.
- Nenhuma imagem capturada receberá tint do tema.
